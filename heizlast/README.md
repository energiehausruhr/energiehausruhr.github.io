# Heizlast-Profi

Ein professionelles Werkzeug zur Heizlastberechnung nach DIN EN 12831.

## Features

- **Raumweise Heizlastberechnung:** Detaillierte Erfassung von Bauteilen (Wände, Fenster, Türen, etc.).
- **Automatische Flächenberechnung:** Berechnet Netto-Flächen basierend auf Breite und Höhe.
- **Klimadaten-Datenbank:** Integrierte Datenbank für deutsche Städte mit Norm-Außentemperaturen und Jahresmittelwerten.
- **U-Wert Rechner:** Werkzeug zur Ermittlung von U-Werten verschiedener Bauteilschichten.
- **Heizkörper Rechner:** Auslegung von Heizkörpern basierend auf der berechneten Heizlast.
- **PDF-Export:** Professionelle Berichte für Kunden und Dokumentation.
- **Responsive Design:** Optimiert für Desktop und mobile Endgeräte.

## Installation

1. Repository klonen:
   ```bash
   git clone <repository-url>
   ```

2. Abhängigkeiten installieren:
   ```bash
   npm install
   ```

3. Entwicklungsserver starten:
   ```bash
   npm run dev
   ```

4. Build für Produktion:
   ```bash
   npm run build
   ```

## Technologien

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Animationen:** Motion (Framer Motion)
- **Diagramme:** Recharts
- **PDF-Generierung:** jsPDF, jsPDF-autotable
- **Icons:** Lucide React
